Privacy policy

Last updated: 13 October 2026

videobot is a private automation tool used only by its owner to publish videos to the owner's own YouTube channel and Instagram account.

What data the app accesses

  • YouTube: the app uses the youtube.upload permission only to upload videos to the owner's channel. It does not read, store or share any other YouTube data.
  • Instagram: the app uses the Instagram Graph API only to publish Reels to the owner's account.

How data is stored

The access credentials are stored as encrypted secrets in the owner's private GitHub repository and are used only to perform uploads. No personal data from other users is collected, sold or shared with third parties.

Google API Services

videobot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
